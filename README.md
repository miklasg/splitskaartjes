# splitskaartjes
## Nieuwe versie online zetten

Pas bij elke wijziging aan `index.html` ook het versienummer aan, op twee plaatsen: `VERSION` bovenaan het eerste script in `index.html`, en `version.json`. Gebruik in beide hetzelfde nummer, bv. de datum en het uur (`202611181900`). De app op de iPad ziet dan bij het openen dat er een nieuwe versie is en laadt die vanzelf.
